## Features

- **Real-time Monitoring** - Display MiniMax API usage in menu bar
- **Multiple Display Styles** - Percentage, raw numbers, progress bars
- **Multi-language** - Chinese, English, Japanese, Korean
- **Launch at Login** - Auto-start on system boot
- **Config File Support** - Read API Key from `~/.mmx/config.json`

## Display Styles

| Style | Description |
|-------|-------------|
| Percentage | `80%` |
| Raw | `800 / 1000` |
| Bar + Percent | Progress bar with percentage |
| Bar + Raw | Progress bar with numbers |
| Bar + Raw + Percent | Full display with all info |

## Progress Bar Colors

8 gradient colors available:

- Sky Blue / Indigo / Teal / Emerald
- Amber / Rose / Violet / Ocean

## Usage

### First-time Setup

1. Click the menu bar icon
2. Right-click and select **Settings...**
3. Enter your MiniMax API Key on the **API Settings** page
4. Select your region (China or Global)

### Quick Actions

| Action | Description |
|--------|-------------|
| Left Click | View all model quota details |
| Right Click | Open context menu |

### Right-click Menu

- **Settings** - Open settings panel
- **Refresh** - Manually refresh quota data
- **About** - View version and author
- **Quit** - Exit the app
